# BrightTech Solutions Website

A responsive company website for BrightTech Solutions, a technology business providing computer hardware, software, networking, and IT support services.

## Project Features

- Dark mode design with red accents
- Responsive layout for desktop, tablet, and mobile screens
- Home page with company branding and welcome message
- About Us section with company history, mission, and vision
- Four technology services
- Four team members with photographs and biographies
- Product cards with images, descriptions, and prices
- Product bundle comparison table
- Contact form with name, email, phone, subject, and message fields
- Navigation links between all sections
- Email, telephone, and Google Maps links
- BrightTech AI button linking to an external AI assistant

## Files

- `index.html` - Main website page
- `style.css` - Website styling and responsive layout rules
- `about.html` - Company history, mission, vision, and values
- `services.html` - Hardware, software, networking, and IT support services
- `team.html` - BrightTech team profiles
- `products.html` - Product catalogue and bundle comparison table
- `contact.html` - Contact details and enquiry form
- `Project 1.html` - Redirect entry page to `index.html`

## How to View the Website

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Internet access is recommended because the website uses external Google Fonts and Unsplash images.

You can also open `Project 1.html`; it redirects to the main page.

## Technologies Used

- HTML5
- CSS3
- Google Fonts
- Unsplash image URLs

No JavaScript, Bootstrap, React, or other frameworks are used.

## AI Assistant

The `BrightTech AI` navigation link and `Ask BrightTech AI` button open ChatGPT in a new browser tab. A live embedded AI model would require JavaScript and a secure backend API, so the external link keeps this project within the HTML and CSS-only assignment restriction.
